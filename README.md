## 📌 About

**Smart Multi-Sensor IoT Monitoring & Control System** is an IoT-based project developed for **IoTrix Hackathon 1.0** by **Team IoT Titans**.

The system collects real-time data from multiple sensors and provides a web-based interface for monitoring environmental and resource conditions.

### Monitored Parameters

- 🌡️ Temperature
- 💧 Humidity
- 🌱 Soil Moisture
- 🚰 Water Level

---

## ✨ Features

- **Multi-Sensor Monitoring** — Collects data from multiple sensors.
- **Real-Time Data** — Provides continuously updated sensor information.
- **Web-Based Monitoring** — Displays sensor data through a web server.
- **Device Control** — Supports control of connected output devices.
- **IoT Integration** — Combines sensors, controller, and web monitoring into one system.
